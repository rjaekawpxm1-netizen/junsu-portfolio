프로젝트 소개

1. 공공사업 제안 인텔리전스 플랫폼 — RFP 분석 + 낙찰이력 기반 수주 판단 도구 (실무, 단독개발)

공공 정보화사업(ISP/ISMP/AX/데이터) 제안 검토를 자동화하는 웹 플랫폼을 나라장터 OpenAPI + Python + Streamlit + Claude/GPT API 기반으로 기획부터 개발·배포까지 단독 수행했습니다.

나라장터 공고를 자동 수집·분류하고, 첨부 제안요청서(PDF·HWPX·HWP)에서 배점표·평가기준·제출서류를 추출해 "어느 항목에 제안을 집중해야 하는지"를 배점 근거와 함께 자동 도출하는 파이프라인을 설계했습니다.

과거 7년 낙찰 데이터 30만 건을 수집·분석하여, 발주기관별 발주패턴·경쟁사 수주이력·낙찰률·컨소시엄 구성을 제공함으로써 "이 사업에 참여할지"를 데이터로 판단하도록 지원합니다.

HWP 바이너리 파싱을 XML 재구조화로 해결하고, 대량 API 수집에 완료마커·자동 재시도·이어받기 로직을 적용해 네트워크 불안정·호출 한도 상황에서도 안정적으로 데이터를 축적했습니다.

전 과정에서 "AI가 지어내지 않고 원문 근거를 인용하는" 검증 체계를 원칙으로 삼아, 배점·조언·기관정보 모두 출처를 추적 가능하게 설계했습니다.

기존 제안 담당자가 공고 검토·기관 조사에 며칠씩 소요하던 업무를, 한 화면에서 즉시 파악하도록 단축했으며 사내 15~20명 대상으로 배포했습니다.

2. FP 자동산정 + 제안요청서 LLM 자동매핑 웹 플랫폼 (실무, 단독개발)

공공SW사업 FP(기능점수) 산정 자동화 도구를 React + Vercel + Supabase + Claude API 기반으로 기획부터 개발, 배포까지 단독으로 수행했습니다.

RFP·기능정의서를 업로드하면 AI가 기능 목록을 자동 생성하고 FP를 산정해 개발비까지 산출하는 파이프라인을 설계했습니다.

프롬프트는 LV1(시스템 메뉴바)·LV2(서브메뉴)·LV3(CRUD 동사) 계층 구조로 설계해 출력 일관성을 확보했습니다.

대용량 문서 처리를 위해 50개 청크 단위 병렬 처리 구조를 적용했고, API Overloaded·RateLimit 상황에서 자동 재시도되는 안정성 로직을 구현했습니다.

그 결과 기존 담당자 수작업 2주 소요 업무를 5분으로 단축했으며, 현재 전사 실운영 중입니다.

3. AI 기반 사내 업무관리 시스템 (실무, 단독개발)

사내 조직(AX본부, 21명) 업무 기록과 보고서 작성을 자동화한 웹 시스템을 Next.js + Vercel + Supabase + Claude API를 활용해 기획부터 배포까지 단독으로 수행했습니다.

매일 업무 내용을 간단히 입력하면 AI가 보고서 문체로 자동 정리하고, 이를 모아 주간보고·월간보고·팀 전체 보고서까지 자동으로 생성하는 구조를 설계했습니다. 파일을 첨부하면 그 내용까지 AI가 정리에 반영하도록 구현했습니다.

개발 과정에서 외부 파일 변환 서비스 오류를 직접 진단해 서버 내부 처리 방식으로 전환했고, 시간대 처리 오류로 아침에 등록한 업무가 어제 날짜로 기록되는 문제를 배포 전 검토 단계에서 미리 찾아 수정했습니다. 배포 후 화면 전환이 느린 문제는 서버 위치와 데이터베이스 위치가 달라서 생긴 것임을 파악하고, 서버 위치를 한국으로 변경해 해결했습니다.

그 결과 매주 반복되던 보고서 수기 작성 업무를 AI 자동 생성으로 대체했으며, 현재 전사 배포 완료 후 실사용 개시 준비 중입니다.

4. AI 학습데이터 품질검증 웹 플랫폼 (실무, 2인 협업 개발 중)

AI 학습데이터 구축사업의 납품 데이터 품질을 검수하는 웹 플랫폼을 Next.js + Supabase(self-hosted) 기반으로 기획·설계부터 개발까지 수행하고 있습니다. 구축업체가 납품한 라벨링·생성 데이터를 사람이 O/X로 검증하는 콘솔을 먼저 구축하고, 이후 규칙·LLM 기반 자동 진단을 결합하는 단계적 구조로 설계했습니다.

사업마다 데이터 구조와 판정 기준이 달라지는 환경에 대응하기 위해, 화면과 판정 기준을 하드코딩하지 않고 JSON 경로 매핑·설정 기반으로 구성하는 동적 스키마 구조를 채택했습니다. 원본 데이터는 정규화 없이 저장하고, 표시 속성·판정 기준·검수 배정을 설정으로 관리해 설정 파일 하나로 프로젝트 간 재사용이 가능하도록 했습니다.

데이터 보안을 고려해 외부 클라우드 대신 사내 서버 self-host 구조(L1 등급 기준)로 설계했으며, 검수자별 접근 제어를 DB 행 수준 보안(RLS)으로 강제하고, 문항 단위 판정을 항목 단위 합·불로 집계하는 롤업 로직을 DB 함수로 단일화해 앱과 향후 자동판정 워커가 동일 규칙을 공유하도록 구성했습니다.

현재 프로젝트 생성·데이터 업로드·표시 속성 매핑·판정 기준 설정·검수자 배정·진행 현황 대시보드까지 구현을 완료했으며, 검수 화면과 규칙·LLM 기반 자동 진단 기능을 개발 중입니다.

5. AI 스트레스 분석 앱 (팀 프로젝트) - 팀장 사용자가 자신의 스트레스 상태를 객관적으로 인지하기 어렵다는 문제에서 출발해 멀티모달 분석 모델을 설계했습니다.

CNN 기반 얼굴 감정 분석과 CNN·LSTM 기반 음성 감정 분석 모델을 결합하고, 설문 데이터까지 더해 가중 평균 방식으로 최종 스트레스 지수를 산출하는 파이프라인을 구현했습니다.

AI 분석 서버·백엔드·Flutter 앱을 분리한 REST API 기반 아키텍처를 설계해, 단순 수치 제공이 아니라 사용자가 직관적으로 이해하고 실제 행동(휴식, 명상 등)으로 이어질 수 있는 표현 방식에 집중했습니다.

5인 팀의 팀장으로서 AI 모델 학습, API 연동, 풀스택 개발을 직접 담당하며 데이터 분석 결과를 실제 서비스로 연결하는 전체 프로세스를 리딩했습니다.
