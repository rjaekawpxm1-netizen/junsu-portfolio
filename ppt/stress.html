AI 스트레스 분석 앱

대학교 팀 프로젝트 · 팀장

휴대폰에서 얼굴 표정, 음성, 설문을 함께 분석해 스트레스 상태를 점수로 보여주고, 그 결과에 맞춰 음악과 영화를 추천하는 팀 프로젝트입니다.

GitHub Repository ↗

왜 만들었나

설문 답변만으로는 응답 시점의 기분에 결과가 달라질 수 있고, 별도 기기를 사용하는 방법은 평소에 쉽게 쓰기 어렵습니다. 팀장으로서 휴대폰에서 확보할 수 있는 입력을 함께 활용하는 방향을 잡고, 데이터 전처리와 분석 구조 설계를 맡았습니다.

주요 기능

  • 휴대폰으로 얼굴과 음성 정보를 입력하고, 설문에 응답합니다.
  • 세 가지 입력에서 얻은 결과를 종합해 0~100 범위의 앱 내 지표로 보여줍니다.
  • 이전 분석 기록을 확인하고, 결과에 맞는 음악과 영화를 추천받습니다.

어떻게 구현했나

AIHub 감정 데이터로 얼굴은 CNN, 음성은 CNN과 LSTM을 결합한 모델로 각각 분석했습니다. 설문 결과를 더해 입력별 비중을 적용하고 하나의 점수로 합쳤습니다.

Flutter 앱에서 입력과 결과를 보여주고, Spring Boot 서버는 사용자 기록과 추천 흐름을 담당하도록 나눴습니다. Python 분석 서버의 결과를 앱으로 돌려줘 점수와 추천을 확인할 수 있게 했습니다.

문제와 해결

  1. 표정이나 음성 하나로 판단하면 결과가 흔들리는 문제

    얼굴과 음성을 따로 분석하고 본인이 응답한 설문을 함께 반영했습니다. 이를 통해 입력 하나의 결과에 의존하는 비중을 줄였습니다.

  2. 점수가 나온 뒤 사용자가 할 일이 없는 문제

    분석 결과를 기록으로 남기는 기능과 음악·영화 추천을 함께 구성했습니다. 사용자 경험에서 결과 확인 이후까지 이어지도록 했습니다.

결과

팀으로 휴대폰에서 입력부터 분석 점수, 기록, 추천까지 이어지는 앱을 구현했습니다. 스트레스 점수는 프로젝트에서 만든 참고 지표입니다.
