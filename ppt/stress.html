AI 스트레스 분석 앱

기여도 100%
GitHub Repository ↗

WHY?

설문만으로 스트레스를 나타내면 응답 시점이나 응답 방식에 따라 값이 달라질 수 있습니다. 별도 장비 없이 휴대폰에서 얻는 얼굴과 음성, 본인이 답한 설문을 함께 활용하는 방향으로 팀 프로젝트를 진행했습니다. 팀장으로서 입력 데이터 정리와 분석 구성에 참여했습니다.

WHAT?

  • 휴대폰에서 입력

    얼굴 표정과 음성을 입력하고 설문에 답하도록 구성했습니다.

  • 세 입력을 합쳐 지표 표시

    얼굴과 음성의 감정 분석 결과에 설문을 더해 0~100 사이의 앱 내 참고 지표로 보여줍니다.

  • 기록과 추천

    과거 분석 기록을 확인하고, 입력을 분석한 뒤 결과에 맞는 음악과 영화 추천을 확인할 수 있도록 앱에 연결했습니다.

HOW?

구현 과정

AIHub 감정 데이터로 얼굴에는 CNN, 음성에는 CNN과 LSTM을 결합한 모델을 사용했습니다. 얼굴과 음성의 분석 결과를 각각 구하고, 설문 결과까지 세 입력에 비중을 적용해 한 지표로 합쳤습니다.

Flutter 앱이 입력과 결과 화면을 보여주고, Spring Boot 서버가 기록 조회와 추천 흐름을 연결하도록 구성했습니다. Python 분석 서버는 얼굴·음성 입력을 처리하고, 결과를 앱에서 볼 수 있게 서버 사이를 연결했습니다.

문제와 해결

  1. 표정이나 음성 한 가지로만 판단하면 값이 흔들리는 경우

    얼굴과 음성은 별도로 분석하고 본인의 설문 응답을 함께 반영했습니다. 입력 하나의 출력이 전체 지표를 좌우하는 비중을 줄였습니다.

  2. 점수를 본 뒤 사용자가 이어서 할 일이 없는 경우

    결과를 기록으로 남겨 이전 값과 같이 볼 수 있게 하고 음악·영화 추천을 연결했습니다. 입력부터 결과 확인과 후속 사용까지 앱 안에서 이어지도록 구성했습니다.

결과

팀으로 휴대폰에서 입력부터 분석 점수, 기록, 추천까지 이어지는 앱을 구현했습니다. 스트레스 점수는 프로젝트에서 만든 참고 지표입니다.
