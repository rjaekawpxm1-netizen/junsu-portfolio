SECOM 반도체 불량 예측

개인 · 데이터 분석·모델링

공개 반도체 공정 데이터에서 불량 가능성을 예측하고, 모델이 어떤 센서 신호를 주요 판단 근거로 삼았는지 분석했습니다.

GitHub Repository ↗

왜 만들었나

공정에는 센서가 590개 이상 있었지만 데이터가 비어 있는 항목이 많고, 불량은 전체의 약 6.6%에 불과했습니다. 정상 제품이 많아서 전체 정확도만 봐서는 실제 불량을 얼마나 찾아냈는지 파악하기 어려웠습니다.

희소한 불량을 구분할 수 있는지, 예측 판단에 어떤 센서가 얼마나 관련되는지까지 확인하는 것을 목표로 잡았습니다.

주요 기능

  • 센서 값과 정상·불량 기록을 정리하고, 분석에 필요한 변수만 추립니다.
  • 기준 모델과 복잡한 패턴을 학습하는 모델을 비교하고, 불량 판단 기준을 조정합니다.
  • 예측에 영향을 준 센서를 확인할 수 있도록 변수 중요도와 개별 예측의 근거를 분석합니다.

어떻게 구현했나

값이 70% 이상 비어 있거나, 값의 변화가 적거나, 다른 센서와 비슷한 정보를 가진 변수를 정리해 202개 변수를 남겼습니다.

기준 모델의 성능을 먼저 확인하고, 센서값 조합에 나타나는 복잡한 패턴을 볼 수 있는 모델과 비교했습니다. 이후 불량 비중과 판정 기준이 결과에 주는 영향을 따로 살폈습니다.

문제와 해결

정상 제품으로 분류하기 쉬워 희소한 불량을 놓치는 문제

학습할 때 불량 사례에 더 큰 비중을 주고, 불량 판단 기준값을 0.3으로 낮춰 불량으로 분류되는 범위를 확인했습니다.

점수만으로는 개선 이유를 설명하기 어려운 문제

모델별 판별 성능을 비교한 뒤, 어떤 센서 값이 불량 판단에 영향을 주었는지 살폈습니다. 이 분석을 통해 우선 확인할 센서 후보를 추렸습니다.

결과

프로젝트 평가에서 정상·불량 구분 성능 지표인 ROC-AUC를 약 0.68에서 0.80으로 높였고, 불량 예측에 영향이 큰 상위 20개 센서를 추렸습니다. 센서 순위는 모델의 예측에 대한 분석 결과입니다.
