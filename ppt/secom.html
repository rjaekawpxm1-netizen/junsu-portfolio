SECOM 반도체 불량 예측

기여도 100%
GitHub Repository ↗

WHY?

반도체 공정 데이터에는 센서가 590개 이상이지만 값이 비어 있는 항목이 많고, 불량은 약 6.6%였습니다. 정상으로 분류하는 것만으로 높게 나올 수 있는 전체 정확도에서 벗어나, 드문 불량을 구분하는지와 어떤 센서가 예측에 영향을 주는지 확인하기 위해 진행했습니다.

WHAT?

  • 센서 데이터 정리

    결측이 많거나 변화가 거의 없는 센서, 정보가 겹치는 센서를 걸러 학습에 쓸 변수를 정리합니다.

  • 불량 판별 성능 비교

    정상·불량을 구분하는 기준 모델과 더 복잡한 패턴을 학습하는 모델을 비교하고, 불량으로 판단하는 기준값을 조정합니다.

  • 센서별 영향 분석

    모델의 예측에 어떤 센서가 영향을 주는지 확인합니다. 개별 예측에 기여한 센서와 전체적으로 중요도가 높은 후보를 살펴봅니다.

HOW?

구현 과정

pandas로 센서 데이터를 정리해 값이 70% 이상 비어 있거나 변동이 적은 변수와 다른 센서와 정보가 겹치는 변수를 걸러 202개를 남겼습니다. 정리된 데이터에서 로지스틱 회귀를 기준으로 잡고, 센서 조합의 비선형 패턴을 학습하는 XGBoost와 비교했습니다.

모델 비교에는 정상과 불량의 점수 순위를 얼마나 잘 나누는지 보여주는 ROC-AUC를 사용했습니다. 최종 분류 기준값은 별도로 조정했고, SHAP으로 센서가 예측값을 불량 쪽이나 정상 쪽으로 얼마나 움직였는지 확인했습니다.

문제와 해결

  1. 전체 정확도만 보면 불량을 놓치는 문제가 가려지는 경우

    학습 시 상대적으로 적은 불량 사례에 더 큰 비중을 주었습니다. 분류 기준값도 0.3으로 낮춰, 기준 변경에 따라 불량으로 판정되는 범위가 어떻게 바뀌는지 확인했습니다.

  2. 수백 개 센서가 겹쳐 중요도를 살피기 어려운 경우

    결측과 변화량, 센서 간 정보 중복을 기준으로 입력을 줄였습니다. 예측 점수와 함께 SHAP 결과를 확인해 어떤 센서를 먼저 살펴볼지 후보를 좁혔습니다.

결과

프로젝트 평가에서 정상·불량 구분 성능 지표인 ROC-AUC를 약 0.68에서 0.80으로 높였고, 불량 예측에 영향이 큰 상위 20개 센서를 추렸습니다. 센서 순위는 모델의 예측에 대한 분석 결과입니다.
