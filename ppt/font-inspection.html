폰트 점검

실무 · 킨코스코리아 · Product Engineer

1프로젝트 개요

PC에 설치된 폰트와 라이선스 근거를 대조해, 인쇄·PDF 사용 가능 범위를 점검하는 기능을 개발했습니다. 출력 작업에서 사용하는 폰트를 확인하고 사용 조건을 살펴보는 과정을 돕는 프로젝트입니다.

2문제 정의 · 추진 배경

출력물에 사용하는 폰트는 모양과 이름뿐 아니라 사용 조건도 함께 살펴봐야 합니다. PC에 설치되어 있다는 사실만으로 인쇄물 제작이나 PDF 납품에서의 사용 범위를 알 수는 없습니다.

설치된 폰트와 관련 근거를 연결하고, 작업 목적에 맞춰 확인할 수 있는 기능을 만들고자 했습니다.

3주요 기능

  • PC에 설치된 폰트를 확인합니다.
  • 폰트에 해당하는 라이선스 근거를 대조합니다.
  • 인쇄와 PDF 사용 목적에 맞춰 확인할 범위를 살펴봅니다.

4사용 흐름

  1. 작업에 사용하는 PC의 설치 폰트를 확인합니다.
  2. 대상 폰트의 라이선스 근거를 함께 살펴봅니다.
  3. 인쇄·PDF 등 사용 목적에 맞춰 필요한 조건을 점검합니다.

설치 여부, 라이선스 근거, 실제 사용 목적을 연결해 확인하는 흐름으로 정리했습니다.

5개발에서 중점을 둔 부분

사용자가 어떤 폰트를 확인하고 있는지와 어떤 용도로 사용할 것인지를 이해할 수 있도록 구성했습니다. 인쇄·PDF 사용 범위를 확인하는 업무에 맞춰 기능을 개발했습니다.

프로젝트의 목적은 관련 근거를 바탕으로 사용 범위를 점검하도록 돕는 것입니다. 폰트별 세부 조건은 해당 라이선스 근거를 확인해야 합니다.
