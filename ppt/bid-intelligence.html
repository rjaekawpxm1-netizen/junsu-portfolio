공공사업 제안 인텔리전스 플랫폼

실무 · 씨에이에스 · 단독 기획·개발

나라장터 공고와 제안요청서, 발주기관의 과거 낙찰·계약 이력을 모아 공공사업 참여 여부를 검토하는 사내 도구입니다. 수집부터 분석과 대시보드까지 담당했습니다.

GitHub Repository ↗

왜 만들었나

초기 버전은 제안요청서를 요약해 문서 검토 시간을 줄이는 데 초점을 맞췄습니다. 실무 피드백을 받고 보니, 담당자가 먼저 답해야 할 질문은 이 사업에 참여할지였습니다. 그 판단에는 문서 한 건의 내용과 함께 발주기관이 과거에 어떤 사업을 발주했고 누가 수주했는지도 필요했습니다.

공고 검색, 문서 검토, 기관 이력 확인으로 나뉘어 있던 작업을 같은 화면에서 할 수 있도록 확장했습니다.

주요 기능

  • 나라장터 용역 공고를 수집하고 사업 유형·참여 검토 기준으로 분류합니다.
  • 첨부 문서에서 참가 자격, 사업금액, 평가기준·배점, 제출 요건과 원문 근거를 정리합니다.
  • 발주기관의 사업 이력, 경쟁사 수주, 컨소시엄 정보를 공고와 함께 확인합니다.

어떻게 구현했나

공고·낙찰·계약 데이터를 불러오고 원본을 보관해, 나중에 새 항목이 필요할 때도 기존 자료에서 다시 정리할 수 있도록 했습니다. 진행이 끊겨도 이미 수집한 데이터를 활용해 이어받을 수 있게 구성했습니다.

첨부 문서는 파일 형식에 맞춰 텍스트를 꺼낸 뒤 필요한 항목을 추출했습니다. 발주기관과 사업 기준으로 과거 데이터를 묶어, 현재 공고의 조건을 이전 이력과 나란히 살펴볼 수 있게 했습니다.

문제와 해결

제안요청서가 여러 형식으로 올라오거나 공고에 빠진 경우

PDF와 한글 문서의 처리 방식을 나눴습니다. 공고에 제안요청서가 없을 때는 연결된 사전규격 문서를 확인하도록 했습니다.

AI가 추출한 정보의 출처를 다시 찾기 어려운 경우

평가기준과 자격 등 주요 항목에 원문 근거를 연결했습니다. 확인할 값이 없으면 ‘정보 없음’으로 표시해, 담당자가 근거를 다시 검토할 수 있게 했습니다.

결과

구축 과정에서 공고 36,212건, 낙찰 785,346건, 계약 2,240,296건을 수집했습니다. 사내에 배포해 당장 검토할 공고를 추리고, 공고 조건과 과거 이력을 함께 보며 참여 여부를 판단하는 데 활용할 수 있도록 했습니다.
