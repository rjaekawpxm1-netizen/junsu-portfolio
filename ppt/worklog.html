AI 업무일지 시스템

기여도 100%
GitHub Repository ↗

WHY?

씨에이에스에서 일일 업무를 이미 기록했는데도, 주간·월간 보고서에 넣을 내용을 다시 찾고 고쳐 쓰는 일이 반복됐습니다. 여러 프로젝트의 기록을 같은 기준으로 분류하고 한 번 남긴 내용을 팀 보고에 다시 쓸 수 있도록 기획부터 배포까지 맡았습니다.

WHAT?

  • 업무일지 등록과 자동 분류

    업무 내용·프로젝트·작성일·상태를 기록하면 AI가 분류하고 보고서에 쓰기 좋은 문장으로 정리합니다.

  • 기간과 프로젝트별 보고서

    선택한 업무 기록을 모아 주간·월간·팀 보고서로 정리하고, Excel 파일로 내보낼 수 있습니다.

  • 첨부 내용 반영

    PDF·Word·Excel·PowerPoint의 내용을 읽어 일지와 함께 정리하고, 보고서를 작성할 때 자료를 다시 찾아 옮겨 적는 과정을 줄입니다.

HOW?

구현 과정

Next.js 화면으로 들어온 업무일지를 프로젝트와 작성일 기준으로 Supabase에 저장합니다. Claude API에는 업무 분류와 문장 정리를 맡기고, 보고서를 만들 때는 먼저 시스템에서 요청 기간과 프로젝트에 해당하는 기록을 추립니다.

첨부파일은 형식에 따라 서버에서 내용을 읽도록 구성했습니다. 읽어낸 자료를 해당 일지와 연결하고, 선택한 기간의 일지와 함께 보고서에 반영하도록 이어 붙였습니다.

문제와 해결

  1. 외부 파일 변환이 실패하면 참고 자료가 빠지는 경우

    외부 변환에 의존하던 방식을 서버 내부 처리로 전환했습니다. 형식에 맞춰 문서를 읽고 첨부 내용과 작성자가 남긴 업무 기록을 함께 정리할 수 있게 했습니다.

  2. 날짜 경계에서 업무일자가 하루 달라지는 경우

    기록의 날짜를 업무에서 사용하는 기준 시간대로 처리하도록 수정했습니다. 주간·월간 보고에서 날짜 경계의 기록을 엉뚱한 기간에 집계하는 문제를 줄였습니다.

  3. 배포 환경에서 조회·저장이 늦어지는 경우

    웹 서버와 데이터베이스의 배포 위치가 다른 점을 확인하고 배포 환경을 조정했습니다. 기능을 추가하는 것과 별개로 사용자가 실제로 기록을 남길 때 응답을 기다리는 시간을 개선했습니다.

결과

일일 기록을 다시 옮겨 쓰는 과정을 줄이고, 업무 등록에서 프로젝트별 분류와 보고서 작성까지 이어지는 시스템을 전사에 배포했습니다. 팀 구성원은 같은 업무 기록을 기간별·프로젝트별로 확인할 수 있습니다.
