AI 업무일지 시스템

실무 · 개인 프로젝트 · 단독개발

기여도 100% 단독개발
GitHub Repository ↗

1프로젝트 개요

매일 하는 업무를 적으면, LLM이 자동으로 정리하고 분류해 주는 업무일지 도구입니다.
일일 기록을 모아 주간·월간 보고서까지 자동으로 만들어 줍니다.
프로젝트별로 업무를 묶어 보여 줍니다.

담당 역할

화면, 서버, LLM 정리 로직까지 혼자 만들었습니다(Next.js 기반).

2문제 정의 · 추진 배경

업무일지는 매일 써야 하는데, 정리하고 보고서로 옮기는 데 시간이 많이 듭니다.
적기만 하면 알아서 정리·분류되고 보고서까지 나오면 좋겠다고 생각했습니다.

기존 방식의 한계

  • 매일 업무를 적고 또 따로 정리해야 한다.
  • 주간·월간 보고서를 만들 때 기록을 다시 옮겨 적는다.
  • 프로젝트가 여러 개면 업무가 섞여 보기 어렵다.
핵심 질문

“업무를 적기만 하면, 정리부터 보고서까지 알아서 만들어 줄 수 있을까?”

3데이터 · 입력 정보

  • 일일 업무 입력(내용·프로젝트·상태)
  • 이슈/특이사항
  • 첨부 파일(pdf·docx·xlsx·pptx)

업무를 등록하면 LLM이 내용을 정리하고 카테고리(AX업무·제안업무·기타)로 나눕니다.
정리된 기록이 쌓여 주간·월간 보고로 이어집니다.

4해결 접근 방식

  • 업무를 등록하면 LLM이 문장을 다듬고 카테고리로 분류하게 했다.
  • 프로젝트별로 업무를 묶어 보여 줬다(가스공사·국기연·국방연동·민통선 등).
  • 일일 기록을 모아 주간·월간 보고서로 자동 정리했다.

5문제 해결 과정

문제 1. 적는 것과 정리하는 게 따로임
문제 상황업무를 적고 나서 또 손으로 정리해야 했습니다.
해결 과정
  • 등록하면 LLM이 자동으로 내용을 정리하게 했다.
  • 카테고리 분류도 같이 하게 했다.
결과적기만 하면 정리와 분류가 한 번에 끝난다.
문제 2. 보고서를 매번 다시 씀
문제 상황주간·월간 보고서를 만들 때 기록을 옮겨 적었습니다.
해결 과정
  • 일일 기록을 모아 보고서 형태로 자동 정리했다.
  • 주간·월간 보기를 따로 뒀다.
결과기록이 쌓이면 보고서가 자동으로 만들어진다.
문제 3. 프로젝트가 섞여 보기 어려움
문제 상황여러 프로젝트를 하면 업무가 뒤섞여 헷갈렸습니다.
해결 과정
  • 프로젝트별로 업무를 묶어 보여 줬다.
  • 진행중 프로젝트를 옆에 따로 표시했다.
결과프로젝트별로 무슨 일을 했는지 한눈에 보인다.

6프로젝트 의의

  • 매일 하는 반복 정리를 LLM으로 자동화했다.
  • 기록에서 보고서까지 한 흐름으로 이었다.
  • 화면부터 서버까지 혼자 만들어봤다.
