실시간 회의 번역

실무 · 킨코스코리아 · Product Engineer

1프로젝트 개요

한국어·일본어·영어 회의의 실시간 자막과 사용자별 언어 표시를 위한 시스템을 개발했습니다. 참가자가 선택한 언어로 회의 내용을 볼 수 있도록 구성한 프로젝트입니다.

2문제 정의 · 추진 배경

서로 다른 언어를 사용하는 참가자가 함께 회의할 때는 각자 이해하기 편한 언어로 내용을 확인할 수 있어야 합니다. 회의가 진행되는 동안 내용을 따라갈 수 있도록 음성과 자막을 연결하는 데 초점을 맞췄습니다.

하나의 표시 언어를 모든 참가자에게 적용하는 대신, 사용자마다 필요한 언어로 볼 수 있는 흐름을 만들고자 했습니다.

3주요 기능

  • 한국어·일본어·영어 회의 내용을 다룹니다.
  • 회의 음성을 실시간 자막과 번역으로 연결합니다.
  • 사용자가 선택한 언어로 회의 내용을 표시합니다.

4사용 흐름

  1. 사용자가 회의 내용을 확인할 언어를 선택합니다.
  2. 회의 중 전달되는 음성을 인식하고 번역합니다.
  3. 사용자별 선택 언어에 맞춰 자막을 표시합니다.

회의의 언어와 각 사용자가 읽는 언어를 연결해, 같은 회의를 각자 필요한 언어로 확인하도록 구성했습니다.

5개발에서 중점을 둔 부분

사용자가 회의 내용을 읽는 흐름과 언어 선택에 따른 표시 방식을 중심으로 개발했습니다. 한국어·일본어·영어를 사용하는 참가자가 자신의 언어로 내용을 확인하는 데 초점을 맞췄습니다.

음성 인식과 번역 결과는 발음·소음·발언 내용에 영향을 받을 수 있습니다. 이 소개에는 확인되지 않은 정확도나 응답 시간 수치를 제시하지 않았습니다.
