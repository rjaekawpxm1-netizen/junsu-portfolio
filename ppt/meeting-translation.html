실시간 회의 번역

기여도 100%

WHY?

킨코스코리아와 일본 본사가 회의할 때, 참가자가 서로 다른 언어로 말해도 대화 흐름을 놓치지 않고 회의 후에 발언을 다시 확인할 수 있는 도구가 필요했습니다. 영어 발언을 포함해 한국어·일본어·영어를 지원하고, 참가자마다 자막을 읽을 언어를 선택하도록 했습니다.

WHAT?

  • 발화 언어 자동 감지

    한국어·일본어·영어 가운데 회의 참가자가 어떤 언어로 말했는지 자동으로 인식합니다.

  • 참가자별 번역 자막

    같은 회의에서도 참가자별 표시 언어를 지정해, 각 화면에서 자신이 이해하기 편한 자막을 읽을 수 있습니다.

  • 화자별 AI 회의록

    회의가 끝나면 AI가 발언을 화자별로 정리합니다. 놓친 논의는 누가 말했는지와 함께 회의록에서 다시 확인할 수 있습니다.

HOW?

구현 과정

LiveKit으로 회의 음성을 전달하고 OpenAI API로 발화 언어를 감지해 자막과 번역을 생성합니다. 화면에서는 회의 전체의 고정 언어를 쓰지 않고, 각 참가자의 표시 언어 선택에 따라 보여줄 자막을 정합니다.

회의 중 처리와 종료 후 처리를 분리했습니다. 진행 중에는 발언을 빠르게 따라갈 수 있도록 실시간 자막을 제공하고, 종료 후에는 화자별로 묶은 회의록을 만들어 발언 경위를 찾기 쉽게 했습니다.

문제와 해결

  1. 말하는 언어와 읽기 편한 언어가 서로 다른 경우

    발화 언어는 음성에서 자동으로 감지하고, 화면 표시 언어는 참가자 설정으로 따로 관리했습니다. 참가자는 발언할 때마다 언어 설정을 바꿀 필요 없이 자신이 선택한 자막을 읽을 수 있습니다.

  2. 시간순 자막만으로는 발언자를 찾기 어려운 경우

    실시간 자막과 별도로 화자별 정리 단계를 뒀습니다. 회의 후에는 논의 내용과 발언자를 함께 찾아볼 수 있도록 회의록 형태로 보여줍니다.

결과

일본 본사와의 실제 회의에서 사용 중입니다. 참가자는 회의 중에 선택한 언어로 발언을 따라가고, 회의가 끝난 뒤에는 화자별 기록에서 확인할 내용을 찾아볼 수 있습니다.
